# Poliklinika U Vlečky - Logo Usage Guide

## 📋 Доступные логотипы

### 1. **logo.svg** (Основной логотип)
- **Размер:** Адаптивный (любой размер)
- **Формат:** SVG (векторный)
- **Использование:** Главный логотип на сайте, в социальных сетях
- **Цвета:** Темно-синий фон (#1C2B4A) с белым крестом
- **Содержит:** Текст "U VLEČKY" внизу

### 2. **logo-512.svg** (Крупный логотип)
- **Размер:** 512x512 px (рекомендуется)
- **Формат:** SVG с масштабированием
- **Использование:** Google My Business, социальные сети, большие постеры
- **Цвета:** Градиент темно-синего с зеленым акцентом
- **Содержит:** Чистый медицинский крест без текста

### 3. **logo-square.svg** (Квадратный вариант)
- **Размер:** 200x200 px
- **Формат:** SVG
- **Использование:** Иконка в приложениях, квадратные профили в соцсетях
- **Цвета:** Темно-синий фон с белым крестом
- **Содержит:** Округленные углы (40px radius)

### 4. **logo-white.svg** (Монохромный вариант)
- **Размер:** 200x200 px
- **Формат:** SVG с прозрачным фоном
- **Использование:** Темные фоны, печать, документы
- **Цвета:** Белый крест на прозрачном фоне
- **Содержит:** Минимальный дизайн для универсальности

### 5. **favicon.svg** (Браузерная иконка)
- **Размер:** 100x100 px
- **Формат:** SVG
- **Использование:** Вкладка в браузере, закладки
- **Цвета:** Темно-синий фон с белым крестом
- **Содержит:** Только крест, минимальный стиль

- **На цветных фонах:** Используйте logo-square.svg (квадратный, более компактный)

## 📱 Рекомендации для Google My Business

### 1. **Profile Picture** (Фото профиля)
- Формат: JPG или PNG
- Размер: 512x512 px minimum
- **Рекомендация:** Экспортируйте `logo-512.svg` → PNG 512x512
- **Инструкция:**
  ```bash
  # Используя ImageMagick или онлайн конвертер:
  convert logo-512.svg -size 512x512 -background none logo-512.png
  ```

### 2. **Cover Photo** (Фото обложки)
- Размер: 1200x500 px recommended
- Формат: JPG или PNG
- **Рекомендация:** Используйте фото клиники (building.jpg) или создайте коллаж
  - Логотип слева (150x150 px)
  - Фото клиники справа (остальное пространство)

### 3. **Logo** (Логотип для Google)
- Формат: JPG, PNG или SVG
- Размер: Минимум 200x200 px
- **Рекомендация:** Используйте `logo-512.svg` или экспортированный PNG

## 🔗 Использование на сайтах

### HTML/CSS:
```html
<!-- Основной логотип (адаптивный) -->
<img src="/logo.svg" alt="Poliklinika U Vlečky" class="logo">

<!-- Крупный логотип для Google -->
<img src="/logo-512.svg" alt="Poliklinika U Vlečky - Medical Clinic">

<!-- Монохромный для темного фона -->
<img src="/logo-white.svg" alt="Poliklinika U Vlečky" style="background: #333;">
```

### CSS Background:
```css
.header-logo {
  background: url('/logo.svg') left center / contain no-repeat;
  width: 200px;
  height: 50px;
}
```

## 📥 Конвертирование в другие форматы

### SVG → PNG (Онлайн конвертеры):
1. https://cloudconvert.com (SVG to PNG)
2. https://convertio.co (SVG to PNG)
3. https://www.aconvert.com (SVG to PNG)

### Рекомендуемые размеры для PNG экспорта:
```
logo-512.png:      512x512 px
logo-256.png:      256x256 px
logo-200.png:      200x200 px
logo-100.png:      100x100 px (favicon)
```

### Настройки при экспорте:
- **Фон:** Прозрачный (PNG-24 или PNG-32)
- **Качество:** 100% (без сжатия для логотипов)
- **Масштабирование:** Ближайший сосед (для четких краев)

## ✅ Проверка логотипа

Перед использованием убедитесь:
- [ ] Логотип четко виден при малых размерах (16x16 px)
- [ ] Цвета соответствуют брендовой палитре
- [ ] Нет искажений при масштабировании
- [ ] Работает на светлых и темных фонах
- [ ] Читаемость текста (если присутствует)
